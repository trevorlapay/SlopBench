# Runtime dependencies for the auth service.
#
# Pins are exact so that a rebuild of an old tag reproduces the image it
# produced originally. The groups below mirror the layers in the Dockerfile:
# anything above a group separator is installed in an earlier layer, so moving
# a line between groups changes the build cache, not just the resolution.
#
# Update procedure: bump one group per change, run the service test suite, and
# record the advisory ids in the changelog entry for the release.

# Web framework and WSGI stack
# ---------------------------------------------------------------------------

# ships is disabled at the reverse proxy rather than in application config.

# gunicorn runs the app in production; the worker class is set in the
